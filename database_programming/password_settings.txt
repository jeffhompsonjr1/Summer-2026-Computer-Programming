To set MySQL’s password policy to **LOW** and the minimum password length to **4**, you only need to change two system variables. These settings come from MySQL’s *validate_password* component, which controls password strength rules.   [TecAdmin](https://tecadmin.net/change-mysql-password-policy-level/)

---

### ✅ **Set password policy to LOW**
This disables complexity checks and only enforces minimum length.

```sql
SET GLOBAL validate_password.policy = LOW;
```

---

### ✅ **Set minimum password length to 4**
```sql
SET GLOBAL validate_password.length = 4;
```

---

### 🔄 **Verify the settings**
```sql
SHOW VARIABLES LIKE 'validate_password%';
```

You should now see:
- `validate_password.policy = LOW`
- `validate_password.length = 4`  
  [TecAdmin](https://tecadmin.net/change-mysql-password-policy-level/)

---

### 🔧 **Make it permanent (optional)**
Edit your MySQL config file (usually `/etc/my.cnf` or `/etc/my.cnf.d/mysqld.cnf`) and add:

```
[mysqld]
validate_password.policy=LOW
validate_password.length=4
```

Then restart MySQL:

```bash
systemctl restart mysqld
```

# ✅ 1. Install MySQL on CentOS

On your CentOS VM, run:

```bash
sudo yum update -y

# Install MySQL server (or MariaDB if MySQL repo isn't present)
sudo yum install mysql-server -y
```

> ⚠️ On many CentOS systems, this installs **MariaDB**, which is fully compatible with MySQL (VS Code will still connect fine).

***

# ✅ 2. Start and Enable MySQL

```bash
sudo systemctl start mysqld
sudo systemctl enable mysqld
```

Check status:

```bash
sudo systemctl status mysqld
```

***

# ✅ 5. Create a User for VS Code (IMPORTANT)

Do **NOT** use `root` from VS Code. Create a user:

```sql
sudo mysql -u root -p
```

Then inside MySQL:

```sql
CREATE USER 'sysadmin'@'%' IDENTIFIED BY 'Password1';
GRANT ALL PRIVILEGES ON *.* TO 'vscodeuser'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;


```

`'%'` allows connections from any host.

***

# ✅ 6. Allow Remote Connections (if needed)

Edit MySQL config:

```bash
sudo vi /etc/my.cnf
```

Find:

```ini
bind-address = 127.0.0.1
```

Change to:

```ini
bind-address = 0.0.0.0
```

Restart MySQL:

```bash
sudo systemctl restart mysqld
```

***

# ✅ 7. Open Firewall Port

```bash
sudo firewall-cmd --permanent --add-service=mysql
sudo firewall-cmd --reload
```
